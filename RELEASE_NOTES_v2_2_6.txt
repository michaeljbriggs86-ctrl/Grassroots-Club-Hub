Grassroots Club Hub v2.2.6 — Responsive & Imagery Corrections

Status at source package creation: WRITTEN + TESTED at source level. APK status requires separate artifact build/inspection.

Reason for revision
Installed-device review of v2.2.5 showed three unacceptable defects:
1. a large blank area above the Grassroots Club Hub logo on high-density Android devices;
2. visibly low-resolution/blurred football hero imagery;
3. layout behaviour that still felt stretched/cramped rather than intentionally responsive.

Root cause fixed
- Android WindowInsets were physical pixels but were written directly into WebView CSS variables.
- The same top inset was also being added in more than one auth layer.
- Earlier generated hero exports were only 1400x720 and highly compressed (~100 KB), with visible blur.

v2.2.6 corrections
- MainActivity converts physical insets by Android display density before exposing CSS px.
- Defensive safe-area limits are applied (top 56 CSS px, bottom 72 CSS px).
- Authentication shell no longer reapplies the top inset; the brand header owns it exactly once.
- Hero files replaced with generated 2048x740 JPEG assets (~560 KB each, high-quality encoding).
- Auth DOM no longer adds a duplicate handwritten slogan over hero art.
- The second photographic footer strip is removed.
- Fields/buttons remain 54–56 px minimum on short screens.
- Small phones scroll naturally.
- Foldable/small-tablet portrait receives a wider stacked layout.
- 900+ CSS px layouts use an intentional image/form split.
- Short landscape layouts use a dedicated split layout.
- App-wide overflow/wrapping/min-width protections strengthened for cards/forms/navigation/tables.
