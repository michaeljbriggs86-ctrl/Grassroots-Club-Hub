# Inter font provenance

`inter-variable.woff2` is the unmodified upright Inter variable font from
https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470
(`docs/font-files/InterVariable.woff2`), retrieved 2026-10-10.

`inter-OFL.txt` is that revision's `LICENSE.txt`, included unchanged.
The font is self-hosted in both client assets and the protected browser bundle;
no external font request is needed. It uses `font-display: swap`.
